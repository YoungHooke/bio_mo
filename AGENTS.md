# AGENTS.md

## Обзор

Проект по моделированию вертикальной миграции зоопланктона (DVM, diel vertical
migration). Пайплайн из трёх этапов:

1. **Генерация данных** — `generate_data.py` симулирует среду, для каждого
   примера решает оптимальную стратегию через `scipy.optimize.minimize` и
   размечает пример по амплитуде миграции.
2. **Нейросеть** — простой полносвязный перцептрон на PyTorch (кода и
   зависимости `torch` в репозитории пока нет — добавить через `poetry add torch`).
3. **Обучение и тест** — на сгенерированном из этапа 1 датасете.

## Команды

- Запуск генерации данных: `poetry run python generate_data.py`
  - Результат: `dvm_dataset.npz` с `X` (N×84, float32), `Y` (0/1, int64), `B` (оптимальные амплитуды). Артефакт НЕ в `.gitignore` — не коммить перегенерированные датасеты.
- Тестов, линтера, typecheck и CI нет. Проверка изменений — запуск скрипта.
- Нужен Python >= 3.12; numpy >= 2 (скрипт использует `np.trapezoid`, а не `np.trapz`).

## Спецификация датасета

- `X` содержит 84 признака: 4×20 профилей датчиков (`E` — пища, `Sx` — хищник по глубине, `St` — суточный ход хищника, `G` — стресс) + 4 веса популяции `(alpha, beta, gamma, delta)`.
- Метка: `Y = 1` тогда и только тогда, когда оптимальная амплитуда `B_opt >= migration_threshold` (по умолчанию 20 м).
- `__main__` генерирует только 200 примеров; в комментарии кода сказано, что для итоговой выборки нужно `num_samples=10000`. Генерация медленная (Nelder-Mead на каждый пример), поэтому тестовые прогоны держать маленькими.

## Соглашения

- Комментарии, докстринги и вывод на печать — на **русском**. Держать доменную терминологию и новые комментарии на русском.
- При первом упоминании любого сокращения или сложного термина всегда давать объяснение (например, DVM — diel vertical migration, суточная вертикальная миграция; ХПС — холодный промежуточный слой).
- При описании части кода показывать сам код (соответствующий фрагмент), а не только пересказывать его словами.
- `evaluate_fitness` использует жёсткий штраф `-1e6` для физически некорректных стратегий (выход за пределы водного столба 0…-140 м); сохранять его при изменении модели.
